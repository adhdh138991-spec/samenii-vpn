# SAMENI VPN — پروژه Flutter برای Android

## وضعیت
این بسته، سورس Flutter و فایل‌های پایه Android Studio را آماده می‌کند. در محیط فعلی Flutter/Android SDK نصب نبود؛ بنابراین APK ساخته یا روی دستگاه آزمایش نشده است.

## نیازمندی‌ها
- Flutter SDK (نسخه پایدار)
- Android Studio و Android SDK
- JDK 17
- اینترنت برای دریافت پکیج‌ها و فایل‌های Gradle

## ساخت APK در Windows
1. فایل ZIP را استخراج کنید.
2. پوشه `SAMENI_VPN` را در Android Studio باز کنید یا در ترمینال وارد آن شوید.
3. اجرا کنید:

```powershell
flutter doctor
flutter pub get
flutter analyze
flutter build apk --release
```

4. خروجی در این مسیر ساخته می‌شود:

`build\app\outputs\flutter-apk\app-release.apk`

برای نصب با ADB:

```powershell
adb install -r build\app\outputs\flutter-apk\app-release.apk
```

## استفاده
1. برنامه را باز کنید.
2. از تنظیمات، لینک Subscription معتبر و مورد اعتماد را وارد کنید.
3. روی «به‌روزرسانی» بزنید.
4. روی «اتصال به بهترین سرور» بزنید و مجوز VPN اندروید را تأیید کنید.

## نکات فنی و امنیتی
- هسته این نسخه از پکیج `flutter_v2ray` استفاده می‌کند که در Android از Xray core استفاده می‌کند؛ این نسخه sing-box نیست.
- این برنامه خودش سرور رایگان ایجاد نمی‌کند. باید لینک اشتراک/کانفیگ معتبر داشته باشید.
- کانفیگ عمومی رایگان می‌تواند ناامن، ناپایدار یا تحت نظارت اپراتور سرور باشد. برای حساب‌های بانکی و اطلاعات حساس از منابع ناشناس استفاده نکنید.
- کمترین تأخیر (ping) لزوماً به معنی بیشترین سرعت یا پایداری نیست.
- لینک Subscription در SharedPreferences ذخیره می‌شود؛ از لینک خصوصی اشتراک محافظت کنید.
- فایل APK فعلی در صورت ساخت، با کلید debug امضا می‌شود و برای انتشار عمومی مناسب نیست. برای انتشار، کلید release اختصاصی بسازید و امضا را تنظیم کنید.
- برای انتشار در Google Play، سیاست‌های VPN و افشای شفاف جمع‌آوری/مسیر‌دهی ترافیک را رعایت کنید.
